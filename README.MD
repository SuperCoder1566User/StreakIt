# How to get a groq API key
1. Go to https://groq.com
2. Signup
3. Go to https://console.groq.com/keys
4. Press "+ Create API Key"
5. Put no expiration date
6. Name it whatever you want
7. Copy the Groq API key and put it in .env

You get quests to complete and you  have to upload
an image of you completing that quest and each quest
completed gives you one streak point and if you already got a streak point that day,
